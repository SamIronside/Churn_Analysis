# assets

Top-level directory for static assets used in the Churn_Analysis project.

Subdirectories:
- charts/ — generated chart images and visualization outputs (PNG, SVG, etc.).

This README ensures the `assets/` directory is tracked by Git. Charts and other output files should be placed in the appropriate subdirectory. If you prefer not to store large binaries in the repository, add patterns to `.gitignore` and keep artifacts in a release or external storage.
